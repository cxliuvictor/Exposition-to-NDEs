# Three-Week Calendar

This is the default schedule. If one session runs long, prioritise the timed project/mock over extra course completion.

## Week 1 — fluency

### Day 1
- Notebook 0: Jupyter environment
- Notebook 1: pandas transformations
- Kaggle Learn: Pandas lessons/exercises

### Day 2
- Notebook 2: NumPy + transforms
- Redo the hardest pandas operations from memory
- Kaggle: remaining Pandas

### Day 3
- Notebook 3: EDA + matplotlib
- Kaggle Data Visualization: line/scatter/distributions/choosing plots only

### Day 4
- Notebook 4: cleaning + feature engineering
- Kaggle Data Cleaning: missing data, scaling/normalisation, dates
- Read `FEATURE_TRANSFORMATION_PLAYBOOK.md`

### Day 5
- Notebook 5: regression + validation
- Kaggle Intermediate ML: pipelines, CV, leakage, boosting

### Day 6
- Notebook 6: classification + thresholds
- Finish Intermediate ML
- Review metrics sheet

### Day 7
- Notebook 7: 120-minute closed-book mastery test
- Mark with `week1/solutions/ANSWER_KEY.md`
- Redo weak sections from a fresh kernel
- Do not advance until you can complete the core workflow without AI

## Week 2 — five research projects

### Day 8
Project 1: anonymous superconductivity regression
- 2.5–3h analysis
- 20–30m mini-deck
- 5m presentation + defence

### Day 9
Project 2: cross-sectional S&P 500
- 3h analysis
- deck + defence
- focus on timing/alignment/costs

### Day 10
Project 3: PJM demand forecasting
- 3h
- finish Kaggle Time Series alongside it
- focus on transformations and ablation

### Day 11
Project 4: Adult income classification
- 2.5–3h
- focus on mixed types / imbalance / threshold decisions

### Day 12
Project 5: Air Quality sensor regression
- 3h
- focus on cleaning, drift and edge regimes

### Day 13
Review day
- compare all five projects using `PROJECT_SCORING_RUBRIC.md`
- redo the weakest 45-minute segment from scratch
- make a list of repeated mistakes

### Day 14
Feature/validation consolidation
- revisit transformation playbook
- reimplement your weakest feature families without notes
- practise 2 x 5-minute presentations from Week 2 projects
