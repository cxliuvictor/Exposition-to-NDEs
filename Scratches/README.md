# Quant Dataset Interview Cheatsheets

Fast-reference notes for a Jupyter-based dataset / forecasting interview.

## Files

1. `00_ONSITE_WORKFLOW.md` — what to do from minute 0
2. `01_PANDAS.md` — filtering, groupby, merge, reshape, dates, rolling
3. `02_NUMPY.md` — arrays, masks, broadcasting, ranking, vectorisation
4. `03_VISUALISATION.md` — matplotlib + seaborn recipes
5. `04_CLEANING_FEATURE_ENGINEERING.md` — missing, outliers, leakage, transformations
6. `05_SKLEARN_MODELLING_VALIDATION.md` — preprocessing, regression, classification, CV, metrics
7. `06_TIME_SERIES.md` — chronological validation, lags, rolling, cyclic features, forecasting
8. `07_STATS_DIAGNOSTICS.md` — correlations, tests, residuals, bucketed errors
9. `08_JUPYTER_DEBUGGING.md` — environment, imports, package installs, common errors
10. `09_COMMON_RECIPES.md` — end-to-end snippets for likely onsite scenarios
11. `10_OPTIONAL_ML_METHODS.md` — PCA, mutual information, ElasticNet, optional XGBoost, etc.
12. `ALL_IN_ONE.md` — every cheatsheet concatenated for one-file Ctrl+F search

## Core workflow

**understand → audit → plot → clean → split → baseline → model → validate → diagnose → explain**

Use `Ctrl+F` / GitHub search for the method you need. The examples are intentionally compact enough to adapt during the interview.
